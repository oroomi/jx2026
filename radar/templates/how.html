How to read this in 60 seconds

Five short steps. Nothing here is a score from us: every line comes from a public record you can open.

  1. Start page. Startups that showed up in public records lately, newest first. Each line says what was found, when, and links to the record.

  2. Find one startup. Type a name in the box. If nothing is found, try the registered name ending in Oy.

  3. Open its page. Four questions in order: how well it fits, how ready it is, who to introduce it to, what should happen next. Tap See why to see the records behind each answer.

  4. Empty means empty. A grey hatched label such as "not in public records" means we looked and found nothing. We never fill a gap.

  5. The Nordic Blue 19. A check on us: for startups already in a programme, did the public records show them before they joined?
