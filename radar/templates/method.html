Declared ecosystem dataset

{% if eco %}

A research dataset of Finnish startups, their investors and their buyers, built on this server and last verified {{ eco.built }}, is imported as declared data (data/declared/ecosystem/, source ecosystem). It holds {{ eco.entities }} entities ({{ eco.supply }} companies, {{ eco.capital }} capital sources, {{ eco.demand }} buyers and partners), {{ eco.matches_in_dataset }} scored company-to-investor and company-to-buyer pairs, each with a reason string, and readiness evidence for {{ eco.readiness_in_dataset }} companies. Its own confidence words: {{ eco.conf_high }} high, {{ eco.conf_medium }} medium, {{ eco.conf_low }} low. Low-confidence rows are leads, not facts.

Imported here: {{ eco.imported_companies }} companies (matched to the register by business id, then by name, then by website; new ones are tagged ecosystem and are not part of the feed), {{ eco.imported_targets }} capital sources and buyers, {{ eco.imported_matches }} matches covering {{ eco.companies_with_matches }} companies, {{ eco.imported_readiness }} readiness rows and {{ eco.signals }} dated events. Events and job ads without a day are stored as the last day of the month, or 1 January for a year-only date, and labelled; rows without a date stay as evidence text, never as signals. The dataset's free-text summaries are not imported because they name private individuals. The dataset can add evidence beside a readiness level; it never changes a level. On company pages a defunct company gets no leads, and defunct targets are never listed.
